# K053250 usage, from MAME

```
python scripts/k053250_survey.py xexex --frames 120000 --snaps 80 --every 4000 --tag _a120k              # attract
python scripts/k053250_survey.py xexex --frames 120000 --coin 600 --snaps 80 --every 4000 --tag _p120k   # play
```

MAME 0.289. Per frame, at MAME's draw (line 256): reg 4, regs 0-3, and the line packets `draw()`
fetches for the visible area from the displayed buffer, with its offsets, flips and rejections
(`scripts/mame/k053250.lua`, following `k053250.cpp:209-414`). "Drawn" = at least one line not
rejected. Zoom = packet word 2; `0x40` is 1:1, larger shrinks (source step = zoom / 64).

`draw()` reads `buffer[page]`, and `dma()` fills `buffer[page]` then flips `page`
(`k053250.cpp:416-426`): the frame shows the table of the DMA before the latest one.

bits 7-5 width mode. Bit 1 (DMA strobe) masked out.
